# 3. 本文提出的方法

## 3.1 系统总体框架与多模态定义

本文提出一种面向无人机视觉定位场景的多模态目标位姿跟踪系统。该系统以视觉（双目/单目）与惯性（或其它传感器）的多模态数据为基础，分为视觉观测前端（3.1-3.5节）与跨模态状态估计后端（3.6节）。系统在统一框架内实现了“目标检测—状态判定—特征提取—位姿估计—多模态融合”的完整闭环（见图3-1）。

在单帧视觉前端处理周期中，系统首先利用轻量级目标检测网络提取图像的感兴趣区域（Region of Interest, ROI）；随后，基于目标投影面积的尺度变化，将观测过程离散化为五个连续的跟踪状态，并自适应调度最优的主从特征提取策略；在获取2D-3D观测匹配后，系统通过最小化立体交叉射线误差（或重投影误差）解算目标的六自由度（6-DoF）位姿，辅以后验物理校验以保障输出的可靠性。最终，解算出的视觉位姿将作为观测值，输入后端的跨模态融合滤波器中。

总体架构遵循模块化解耦设计，各模块之间通过统一的数据载体解耦，使得不同特征策略之间可以灵活组合与替换。本文的核心贡献可归纳为以下四点：
（1）提出一种适应大范围连续距离变化的目标五状态分级机制；
（2）构建了多模态（纹理、轮廓、像素外观）互补的混合特征提取策略库；
（3）设计了无环单向退化后备链及跨状态回退机制，显著提升了系统的鲁棒性；
（4）引入基于误差状态卡尔曼滤波（ESKF）的多模态融合框架，实现跨状态的高精度位姿估计。

## 3.2 基于面积判定的五状态目标分级

随着无人机与目标的相对距离缩短，目标在成像平面上的投影面积呈指数级跨越，其有效视觉线索从微弱像素群（远距）、高对比度轮廓（中距）逐渐向丰富表面纹理（近距）演变。不同距离下的观测信息瓶颈决定了单一特征提取算法无法在全包络工作区间内保持鲁棒——不同方法各自的适用区间在距离维度上是互补的。为此，本文提出基于投影面积的五状态目标分级机制。

目标检测网络输出两类包围盒（Bounding Box）：整体轮廓（class 0）与中心区域（class 1）。系统的状态转移以 class 0 的面积 $s$ 为核心触发条件。具体判定逻辑见公式 3-1：当 $s$ 不超过远距离阈值时判定为远距离（State 1）；当面积处于中等区间时判定为中等距离状态（State 2）；当面积处于中等偏大区间时判定为中近距离状态（State 3）；当 $s$ 超过近距阈值且存在 class 1 时，进入近距离混合观测状态（State 4）。当目标整体因遮挡或截断导致 class 0 丢失、仅检出 class 1 且面积达到设定下限时，系统触发极近距离机制（State 5），以 class 1 重建 ROI 并降级重分类。该机制直接建立在2D图像空间，无需位姿先验，有效隔离了分级与解算间的误差耦合。

## 3.3 多策略混合特征提取

针对五种目标状态在图像外观上的显著差异，本文构建了一个包含三种基础特征提取器与一种混合提取模式的策略库，分别为面向中近距离纹理丰富目标的 AKAZE 描述子匹配策略、面向中等距离多边形标识物的二值角点提取策略、面向远距离微小目标的超分辨率微目标提取策略，以及面向近距离大目标的 Dual-ROI 混合提取策略。三种基础策略在特征模态上相互独立，这种模态层面的互补性使策略库能够在退化链机制下逐级支撑。

### 3.3.1 AKAZE 描述子匹配策略

AKAZE 描述子匹配策略面向中近距离、表面纹理丰富的目标，是系统在绝大多数正常跟踪情况下使用的主策略。该策略在特征提取阶段同时利用了目标的局部外观描述与双目图像的几何约束。为建立左右图像之间的特征对应，策略引入了金字塔光流追踪，并以双向一致性的前向后向误差阈值剔除错误对应。为建立图像特征与模板特征之间的对应，系统对左图关键点与模板关键点执行包含比率检验、交叉检验与单应性随机抽样一致性检验三个阶段在内的级联匹配，在保证匹配精度的同时兼顾了运算效率。

### 3.3.2 二值角点提取策略

二值角点提取策略面向中等距离、具备清晰多边形轮廓的目标。该策略首先以自适应阈值方法（Otsu）对 ROI 进行二值化；随后通过连通域分析选取目标，并进行平滑处理。为消除目标平面内旋转带来的影响，策略预置了按 15° 步长旋转的 24 个方向的模板二值图，通过交并比度量检索最佳匹配角度将目标旋转回正；随后利用多边形近似算法提取指定数目的角点，并建立与模板角点的索引关系。这种处理顺序使得角点的提取与匹配对目标的平面旋转具有天然不变性。

### 3.3.3 超分辨率微小目标策略

超分辨率微小目标策略面向远距离、在图像中仅占据极小面积的目标。策略首先利用 Otsu 二值化分离目标与背景，并通过与 24 方向模板匹配确定角度；随后对目标区域实施基于三次插值的固定倍数超分辨率放大，重建细节结构。之后以多指标加权评分（综合考虑矩形度、面积占比合理性、距 ROI 中心距离及长宽比）选出最符合先验形状的连通域；最终提取角点并经亚像素精化与象限对齐，对应到已知三维点。该策略在内部设置了多层校验，以避免错误对应引入位姿解算。

### 3.3.4 Dual-ROI 混合策略

针对近距离目标，单一特征模态的信息已不足以充分利用外观线索。Dual-ROI 混合策略在同一帧内对两个 ROI 并行执行两种模态的互补特征提取：对 class 0 界定的目标整体区域执行二值角点提取，捕获边缘与轮廓强几何约束；对 class 1 界定的中心区域执行 AKAZE 描述子提取，捕获内部纹理信息。合并阶段将中心区域提取点平移统一坐标系后，结合模板匹配确定的角度关系，将两路观测点及对应三维点合并为最小二乘输入，显著增加了位姿求解的约束数量。

## 3.4 单向退化后备链与跨状态重分配机制

在实际飞行场景中，光照突变、运动模糊、局部遮挡以及目标姿态变化都可能使当前帧所选主策略的特征提取失败。为此，本文设计了跨状态的观测退化处理机制以保证跟踪连续性。

首先，在同一状态层级内，构建无环单向退化后备链。当主策略提取失败时，系统沿预设的退化方向逐级降级到信息利用率更低、但鲁棒性更强的后备策略，直至某一策略成功或退化链耗尽。策略链按照“AKAZE 描述子策略 → 二值角点策略 → 超分辨率微目标策略”顺序组织。退化方向始终从高判别力指向低判别力，且不跨区间折返，避免了策略间的往复震荡。退化链的触发条件形式化为公式3-2。

## 3.5 位姿解算与后验校验

### 3.5.1 双目交叉射线 GPnP 优化

在双目配置下，系统采用基于交叉射线约束的全局位姿优化方法（GPnP）。GPnP 将位姿求解构造为最小化模型点对两条观测射线距离的非线性最小二乘问题，其残差向量由左右视图各自的向量叉积残差拼接构成（见公式3-3）。优化问题以四元数与平移向量构成的七维向量作为优化变量，采用 Levenberg–Marquardt 算法求解，并在双目模式下维护帧间位姿缓存（warm-start）以加速收敛。与重投影误差相比，交叉射线约束对深度方向的估计更为稳健。

### 3.5.2 首帧初值解算与单目位姿解算

为向 GPnP 提供可靠的初始猜测，系统在首帧或 warm-start 缓存失效时启用初始位姿解算器。该解算器以 RANSAC 方式进行鲁棒估计并辅以非线性精化。在单目模式下，系统采用 EPnP 算法配合 RANSAC 进行位姿估计。针对微小目标近距离下二维观测点聚集导致深度估计病态化的问题，单目解算器在精化前保存 RANSAC 结果，若检测到精化结果发散则自动回退，避免输出无效位姿。

### 3.5.3 位姿有效性校验

所有位姿解算器输出的结果均需通过统一的物理有效性校验，作为进入后端融合前的最后一道安全保障。校验条件包括：相机必须位于目标前方、平移范数符合工作距离区间、旋转与平移分量须为有限值、以及有效点数达到下限（见公式3-4）。未通过校验的解算结果将触发上一节的退化机制。

## 3.6 基于 ESKF 的多模态信息融合

作为系统的跨模态状态估计后端，本模块接收 3.5 节输出的视觉观测位姿，并结合高频惯性测量单元（IMU）等其它模态的预积分数据，通过误差状态卡尔曼滤波（Error-State Kalman Filter, ESKF）进行紧耦合/松耦合融合。该框架利用 IMU 提供的高频运动先验，有效弥补了视觉特征提取在极端退化场景下的短板，从而输出平滑、高频率且全局一致的最终六自由度位姿。
