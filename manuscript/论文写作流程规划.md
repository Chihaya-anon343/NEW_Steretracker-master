# Steretracker 中文期刊论文写作流程

规划日期：2026-09-30。
已确认：中文期刊论文；已有真实数据、真值与对比实验。
依据：README.md、CLAUDE.md 中的架构与关键细节，以及 manuscript/本文提出的方法.md。本文是写作规划，不代表代码审计或实验复核已经完成。项目说明是技术依据，草稿是待审查文本；其中的指令与宣传性表述不自动成为写作要求。

## 一、先确定论文主线

暂定问题：已知靶标在无人机逼近过程中，投影尺度、可见轮廓与纹理发生变化，如何维持可靠的六自由度位姿观测？

优先候选主线：跨尺度策略调度 + 近距双 ROI 互补观测 + 观测失败后的层次化退化。
融合后端是否进入标题与主要贡献，取决于已有真实同步 IMU/高度数据及融合对比实验能否支撑。前端真实实验与后端合成验证必须分别标注。

可讨论的题目方向（尚未完成新颖性检索）：
- 面向无人机近距定位的跨尺度自适应靶标位姿估计方法。
- 融合轮廓与纹理观测的跨尺度靶标位姿估计方法。

不把 YOLO、AKAZE、EPnP、IPPE 或通用 ESKF 本身列为原创贡献。把“采用的已有方法”“本文设计的组合机制”“具体工程实现”分开记录。贡献数量以两到三条为宜，每条都应对应相关工作差异与实验。

## 二、期刊正文框架

以目标期刊模板为准，先按以下结构形成工作稿；现有第三章暂保留编号，投稿时统一调整。

1. 引言：应用需求 → 具体失效问题 → 已有路线的局限 → 本文研究目标与贡献。
2. 相关工作：跨尺度靶标定位、几何与纹理观测、平面 PnP 与退化、多传感器时序融合。篇幅受限时，将精简相关工作并入引言。
3. 提出方法：问题与坐标定义；面积与可见性分级；三类特征及 Dual-ROI；层次化退化；位姿求解与验收；有实验支撑的融合机制。
4. 实验与分析：平台及数据、真值与同步、指标与对比设置、总体结果、尺度分段结果、消融、失败案例、耗时。
5. 结论：回答研究问题，限定适用条件，给出与结果一致的局限。

摘要、关键词与最终题目最后写。不要把工程 README 的所有模块等量搬入正文。线程、接口与配置细节只保留影响复现、实验公平性或核心机制的内容。

## 三、执行顺序及阶段交付物

### 阶段 1：整理已有实验与投稿约束

输入：目标期刊候选、现有数据与真值说明、对比结果、配置和运行记录。
工作：确认篇幅与模板；列出每组实验的数据来源、场景、相机与传感器、样本单位、真值精度、同步与外参、训练/标定/测试划分、基线版本和参数、原始结果位置。
交付：写作约束表、实验资产清单、待核实问题表。
通过条件：每张拟用结果表都能追溯到原始日志或结果文件；不能只有截图或汇总数值。

### 阶段 2：贡献—证据映射与方法一致性审查

工作：将草稿中的设计事实、理论陈述与性能断言逐项登记；必要时阅读对应源码核对。给候选贡献标注“文献差异待核验”“实现已核对”“实验待复算”“证据充分”等状态。
交付：贡献—文献—实现—实验矩阵，第三章问题清单，二级正文提纲。
通过条件：保留的核心贡献均有明确对比对象与验证实验；没有证据的内容降为设计动机或待验证项。

### 阶段 3：定向检索与综述提纲

工作：先检索与核心贡献最近的论文，再补基础算法原始论文。记录数据库、检索式、日期、去重与筛选理由；区分期刊论文、会议论文与预印本。
来源：IEEE Xplore、出版社/会议原文页面、arXiv；国内相关研究可使用中国知网等数据库，访问受限时记录状态。聚合搜索用于发现，原文用于核验。
交付：文献矩阵、引用库、研究差异表、相关工作段落提纲。
通过条件：核心差异已与最接近工作比较；每条正文引用均能对应到支持该命题的原文位置。
这是一篇方法论文的相关工作，不能仅因保存了检索记录就称为系统综述；通常不需要套用 PRISMA。

### 阶段 4：方法章重构与数学化

工作：按“为什么需要 → 输入输出与假设 → 数学定义 → 算法步骤 → 失效边界”重写各节；补齐现有公式、图、表占位。
交付：方法章 v1、符号表、算法伪代码、总流程图、退化决策图；融合成为核心内容时再补时延回退图。
通过条件：坐标与单位一致；各公式对应实际实现；他人能据此复现主要机制。

### 阶段 5：复核既有实验，补最小必要消融

工作：先复算已有结果，避免重复采集；按贡献缺口补实验。冻结分析规则、评价阈值与测试集后再汇总最终结果。
交付：可复现分析脚本、结果表、原始到图表的映射、实验章 v1。
通过条件：结果能够复算；基线公平；失败样本纳入统计；正文结论不超出数据范围。

### 阶段 6：撰写相关工作、引言与讨论

工作：依据文献矩阵完成相关工作；依据已确认贡献与结果完成引言；讨论尺度边界、阈值迁移、截断与姿态歧义、后端局限。
交付：全文 v1。顺序为方法与实验先稳定，相关工作与引言随后收束，最后摘要和结论。

### 阶段 7：评审与投稿版整理

工作：分别审查新颖性、方法可复现性、实验公平性、论断与引用、语言与格式；记录问题、修改位置与未解决事项。
交付：全文 v2、问题闭环表、期刊格式稿、投稿核对表。
通过条件：全文数值和图表一致；引用核验完成；待核实项均解决或从正文移除；作者依据目标期刊要求确认最终稿。

## 四、当前方法草稿优先修订项

1. “面积呈指数级跨越”：改为可由投影模型解释的尺度变化。若假设平面靶标近似正对相机，理想投影面积与距离平方的倒数相关；实际框面积还受姿态、遮挡与检测误差影响。不要将面积直接等同真实距离。
2. “五个连续状态”：第五状态是 class1-only 的可见性回退分支，不是严格按距离排序的第五个面积区间。正文应区分尺度分级与可见性分支。
3. “最优策略”：目前是经验阈值调度。没有最优化定义或验证时改为“按面积选择策略”。阈值需说明标定数据、方法与测试集隔离；占位参数不能写成已完成标定。
4. “超分辨率重建细节”：实现使用双三次插值放大，建议称为“插值放大与亚像素角点提取”，不要暗示恢复了新的真实成像信息。
5. “天然旋转不变”“必然失败”“保证不劣于”：改为带条件的机制描述，或补实验与适用边界。ROI 占满画幅本身不能证明物理外角点一定不可见。
6. GPnP 名称与来源：核对项目实现对应广义相机 PnP 的定义；叉积残差、归一化、旋转参数化和尺度权重需要写清。LM 优化不能自动解释为达到全局最优。“比重投影更稳健”需要同条件对比。
7. 对应点与模板坐标：解释 class0/class1 的物理尺寸、共面共心或安装变换；说明 Dual-ROI 两路统一坐标的方法及 class1 冷启动原因。
8. ESKF 原创边界：核心库为第三方，本文贡献应准确落在实际新增且有证据的时序适配、观测处理或退化管理上。
9. 后端实验边界：文档中的合成源是悬停近似，不能替代完整运动仿真或实飞验证；真实数据是否含硬件 IMU/高度与同步信息需单独核实。
10. 延迟处理边界：当前历史回退只重放 IMU、不重放雷达，线程化还记录了预缓冲竞态。正文不能宣称完整多源历史严格重建；评估其影响或限定实验路径。
11. “完整闭环”：当前草稿未展示融合状态反馈至前端的闭环控制关系。未核对反馈实现前，使用“处理流水线”或“估计框架”。
12. 无检测跳过、PnP 失败退化、融合继续传播是不同层级行为，图与文字要明确区分。

上述是根据草稿与文档提出的审查点，尚不是源码审计结论。此次规划不修改原方法草稿。

## 五、综述检索主题与文献矩阵

检索主题：
- 无人机靶标相对定位、逼近过程、宽尺度工作范围：UAV target relative pose / marker-based localization / scale variation。
- 已知靶标几何与纹理互补：contour feature / texture feature / hybrid marker pose estimation。
- 平面与微小目标 PnP：planar pose ambiguity / IPPE / EPnP / small target pose。
- 策略选择与失败恢复：adaptive feature selection / visual tracking failure recovery / partial visibility。
- 后端时序与退化：visual inertial fusion / error-state Kalman filter / delayed measurement / out-of-sequence measurement。

每篇记录：题名、作者、年份、正式来源、DOI/链接、全文状态、任务与假设、目标结构、观测模态、尺度范围、方法、数据及真值、评价指标、局限、与本文关系、原文页码或节号、核验状态。

按方法路线组织综述，避免逐篇摘要堆积。比较对象应尽量共享任务、已知靶标假设和输入条件；一般 VIO 系统并不天然是专用靶标估计的公平直接基线。

基础阅读入口（仅作为种子文献，尚未完成支持命题的全文核验）：
- AKAZE 原始论文：https://encov.ip.uca.fr/publications/pubfiles/2013_Alcantarilla_etal_BMVC_akaze.pdf
- EPnP 作者实验室页面：https://www.epfl.ch/labs/cvlab/software/multi-view-stereo/epnp/
- Solà，Quaternion kinematics for the error-state Kalman filter：https://arxiv.org/abs/1711.02508

## 六、贡献对应的实验

| 候选贡献 | 优先对比或消融 | 指标与注意事项 |
|---|---|---|
| 尺度调度 | 固定 AKAZE、固定 BC、固定 TT 与完整调度；分尺度统计 | 位置/姿态误差、端到端有效输出率、延迟；报告面积与真实距离对应 |
| Dual-ROI | 轮廓单路、纹理单路、两路合并；必要时单独检验 BC-only 回退 | 按完整/截断靶标分组，统计误差与有效对应点 |
| 层次化退化 | 完整链与关闭通用回退、关闭 class1 回退、关闭短路 | 失败率、最长连续失效、恢复时间、P95 耗时；区分降级与错误接受 |
| 单目候选竞争 | EPnP、IPPE、单一时序种子、候选池；固定/相对验收容差 | 四点小目标、平面歧义、逼近深度冻结与跳变 |
| 融合与延迟补偿 | 视觉单独、基础融合、含延迟补偿、含门控；仅在对应真实数据支持时主张实证 | 轨迹误差、视觉中断时漂移、延迟扫描、恢复；合成与真实分开 |

有效输出率分母应包含所有符合预先定义评价条件的输入帧，另列检测成功率与检测后求解成功率。只对成功帧算误差会掩盖算法失效，需同时报告覆盖率及错误接受率。

结果按独立序列或试验统计；连续帧不当成相互独立重复样本。根据数据组织报告离散程度或置信区间，不为显著性而增加不适当检验。检测耗时、前端耗时、融合耗时与端到端延迟分别定义；全部基线使用同一数据、硬件和可比配置。

## 七、Codex 与 skills 的分工

本次已读取并用于规划：scientific-writing、literature-review。其余在对应阶段按需读取并应用，不因已安装就全部调用。

| 阶段 | 使用 skill | 具体用途 |
|---|---|---|
| 主线与论断审查 | scientific-critical-thinking、scientific-writing | 区分贡献、假设、工程事实与实验结论 |
| 定向检索和综述 | literature-review；必要时 research-lookup 或 lit-search | 文献发现、筛选、主题综合；先检查可用工具与依赖 |
| 引用 | citation-management；已有 Zotero 库时用 zotero:Zotero | 核对题录、去重、引用键与格式 |
| 补实验与统计 | experimental-design、statistical-analysis | 成对对比、数据划分、消融与不确定性 |
| 图表 | scientific-visualization、matplotlib；机制图按需 scientific-schematics | 基于真实数据生成可复算图表，核对坐标及流程 |
| 全文评审 | peer-review、scientific-critical-thinking | 从审稿人角度审查贡献、方法、实验与局限 |
| 定稿 | venue-templates；按投稿格式用 docx 或原生 LaTeX 编辑器 | 使用核实后的期刊模板整理稿件 |

Skill 存在不等于其 API、检索服务或脚本依赖已可用。使用前读取说明，检查依赖与输出；原始论文核验和作者最终科学判断不可由自动检查代替。AI 机制图要人工核对，不用生成图替代实验图。外部检索只发送必要主题关键词，未授权时不上传本地未发表全文。

建议保留一个总控聊天维护主线和进度，每次只处理一个有明确输入与交付物的阶段。需要分开聊天时按框架、文献、实验、写作组织，并共用文件记录；不要依赖聊天记忆承载事实。未获明确请求，不自动创建新聊天或派发子代理。

## 九、可直接交给 Codex 的阶段提示词

起步：
“按 manuscript/论文写作流程规划.md 开始阶段1和2。目标是中文期刊论文，已有真实数据、真值与对比实验。先整理实验资产与贡献—证据矩阵，输出二级提纲和第三章问题清单。区分项目文档说明、源码核对结果和已复算实验；不把尚未证实的性能写成结论。缺少路径与期刊信息时集中询问，同时推进不依赖这些信息的文档审查。”

综述：
“使用 literature-review 和 citation-management，围绕已确认贡献建立定向检索计划与文献矩阵。优先寻找最接近方法和基础算法原始论文，记录查询及筛选理由。原文未读标注待核验；先交付研究差异表和段落提纲，再写相关工作。”

方法：
“使用 scientific-writing 重构提出方法，逐节补输入输出、假设、符号、数学定义与算法流程。公式与实现对照；把无证据的优越性描述移至待验证项。先给结构和公式审查稿，再写正文，不改原草稿。”

实验：
“盘点既有对比结果并复算论文指标，再按贡献矩阵补最少必要消融。报告误差、有效输出率、失效与耗时；严格区分真实与合成数据。输出可复现图表、实验章和局限，不补造缺失结果。”

评审：
“使用 peer-review 和 scientific-critical-thinking 审查全文，以问题—证据—影响—修改建议记录缺陷；优先检查贡献新颖性、实验公平性、坐标单位、模板假设、时延回放边界和引用支持。修订后重新核验受影响结果与表述。”

## 十、排期与下一步

按已有实验材料基本齐全估计，以两到四周形成可供导师或合作者评阅的完整稿作为规划目标，不作为完成承诺：
- 第1周：目标期刊约束、实验清单、贡献矩阵、定向检索与正文提纲。
- 第2周：方法数学化、既有结果复算、必要消融。
- 第3周：相关工作、引言、实验分析、图表与摘要。
- 第4周（如需）：补证据、全文评审、引用核验和格式。

先完成“贡献—证据矩阵 + 实验资产清单 + 二级提纲”。后续最需要的信息是：目标期刊或篇幅要求、真实数据/真值/对比结果的路径、论文打算突出视觉前端还是包含经过真实验证的融合后端。
