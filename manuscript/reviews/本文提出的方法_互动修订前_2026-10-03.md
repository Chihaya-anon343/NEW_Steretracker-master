# 3. 本文提出的方法

## 3.1 系统总体框架与多模态定义

本文提出一种面向无人机视觉定位场景的多模态目标位姿跟踪系统。该系统以视觉（双目/单目）与惯性（或其它传感器）的多模态数据为基础，分为 **视觉观测前端** （3.1-3.5节）与 **跨模态状态估计后端** （3.6节）。系统在统一框架内实现了“目标检测—状态判定—特征提取—位姿估计—多模态融合”的完整闭环（见图3-1）。

在单帧视觉前端处理周期中，系统首先利用轻量级目标检测网络提取图像的感兴趣区域（Region of Interest, ROI）；随后，基于目标投影面积的尺度变化，将观测过程离散化为五个连续的跟踪状态，并自适应调度最优的主从特征提取策略；在获取2D-3D观测匹配后，系统通过最小化立体交叉射线误差（或重投影误差）解算目标的六自由度（6-DoF）位姿，辅以后验物理校验以保障输出的可靠性。最终，解算出的视觉位姿将作为观测值，输入后端的跨模态融合滤波器中。后端滤波器针对多源传感数据的异步性与视觉测量的固有延迟，设计了时间对齐与延迟测量反向传播机制，并在融合过程中内置故障检测隔离与输出质量分级，以保障融合位姿在视觉观测中断或异常时仍然连续可用。

## 3.2 基于面积判定的五状态目标分级

随着无人机与目标的相对距离缩短，目标在成像平面上的投影面积呈指数级跨越，其有效视觉线索从微弱像素群（远距）、高对比度轮廓（中距）逐渐向丰富表面纹理（近距）演变。 **不同距离下的观测信息瓶颈决定了单一特征提取算法无法在全包络工作区间内保持鲁棒** ——不同方法各自的适用区间在距离维度上是互补的。为此，本文提出基于投影面积的五状态目标分级机制。

目标检测网络输出两类包围盒（Bounding Box）：整体轮廓（class 0）与中心区域（class 1）。系统的状态转移以 class 0 的面积 $s$ 为核心触发条件。具体判定逻辑见公式 3-1：当 $s$ 不超过远距离阈值时判定为远距离（State 1）；当面积处于中等区间时判定为中等距离状态（State 2）；当面积处于中等偏大区间时判定为中近距离状态（State 3）；当 $s$ 超过近距阈值且存在 class 1 时，进入近距离混合观测状态（State 4）。当目标整体因遮挡或截断导致 class 0 丢失、仅检出 class 1 且面积达到设定下限时，系统触发极近距离机制（State 5），以 class 1 重建 ROI 并降级重分类。该机制直接建立在2D图像空间，无需位姿先验，有效隔离了分级与解算间的误差耦合。

## 3.3 多策略混合特征提取

针对五种目标状态在图像外观上的显著差异，本文构建了一个包含三种基础特征提取器与一种混合提取模式的策略库，分别为面向中近距离纹理丰富目标的 AKAZE 描述子匹配策略、面向中等距离多边形标识物的二值角点提取策略、面向远距离微小目标的超分辨率微目标提取策略，以及面向近距离大目标的 Dual-ROI 混合提取策略。三种基础策略在特征模态上相互独立，这种模态层面的互补性使策略库能够在退化链机制下逐级支撑。

### 3.3.1 AKAZE 描述子匹配策略

AKAZE 描述子匹配策略面向中近距离、表面纹理丰富的目标，是系统在绝大多数正常跟踪情况下使用的主策略。该策略在特征提取阶段同时利用了目标的局部外观描述与双目图像的几何约束。为建立左右图像之间的特征对应，策略引入了金字塔光流追踪，并以双向一致性的前向后向误差阈值剔除错误对应；对通过校验的立体匹配点，进一步依据视差绝对中位差（Median Absolute Deviation, MAD）准则剔除深度离群点，保证进入位姿解算的点集在深度维度上统计一致。为建立图像特征与模板特征之间的对应，系统对左图关键点与模板关键点执行包含比率检验、交叉检验与单应性随机抽样一致性检验三个阶段在内的级联匹配，在保证匹配精度的同时兼顾了运算效率。

### 3.3.2 二值角点提取策略

二值角点提取策略面向中等距离、具备清晰多边形轮廓的目标。该策略首先以自适应阈值方法（Otsu）对 ROI 进行二值化；随后通过连通域分析选取目标，并进行平滑处理。为消除目标平面内旋转带来的影响，策略预置了按 15° 步长旋转的 24 个方向的模板二值图，通过交并比度量检索最佳匹配角度，将目标旋转回正。旋转回正在二值空间而非灰度空间进行：自适应阈值仅在原始图像上计算一次，旋转产生的边界填充不参与阈值统计，避免了填充像素污染灰度直方图所导致的选域翻转；同时在图像边界预置隔离带，并对旋转后的连通域施加触边判别规则（触边排除、面积占优翻案与高贴边覆盖率守卫），防止填充区域与贴边靶板粘连。随后利用多边形近似算法提取指定数目的角点，并建立与模板角点的索引关系。这种处理顺序使得角点的提取与匹配对目标的平面旋转具有天然不变性。

### 3.3.3 超分辨率微小目标策略

超分辨率微小目标策略面向远距离、在图像中仅占据极小面积的目标。策略首先对 ROI 实施固定倍数的双三次插值超分辨率放大并作平滑处理，在超分辨率空间内完成自适应阈值二值化，以在像素层面重建目标的细节结构。随后执行与二值角点策略同款的品质清理链：基于触边判别规则选取目标连通域——触边排除、面积占优翻案，并在所有候选区域均触边（小目标被 ROI 边缘截断的典型情形）时回退为全局最大域，保证选取结果不劣化——继以孔洞填充与闭、开形态学运算，得到单域实心的目标掩模。清理后的二值图作为角度匹配与角点提取的共用输入：与 24 方向预置模板进行交并比匹配确定目标角度后，提取最小外接矩形的四角点，经亚像素精化与象限对齐，对应到已知三维点。该策略在内部设置了多层校验，以避免错误对应引入位姿解算。

### 3.3.4 Dual-ROI 混合策略

针对近距离目标，单一特征模态的信息已不足以充分利用外观线索。Dual-ROI 混合策略在同一帧内对两个 ROI 并行执行两种模态的互补特征提取：对 class 0 界定的目标整体区域执行二值角点提取，捕获边缘与轮廓强几何约束；对 class 1 界定的中心区域执行 AKAZE 描述子提取，捕获内部纹理信息。合并阶段将中心区域提取点平移统一坐标系后，结合模板匹配确定的角度关系，将两路观测点及对应三维点合并为最小二乘输入，显著增加了位姿求解的约束数量。

两路观测的三维模板点在同一坐标系下定义，这是二者能够合并进同一次位姿求解的前提：二值角点路的三维模板并非独立标定，而是从纹理路所用的模板灰度图现场提取角点、按同一物理宽高作中心化处理生成，与纹理路的三维点同源、同尺度、同原点。混合观测模式的失效处理采用专属的三级退化链与主 ROI 短路机制，详见 3.4.2 节。

## 3.4 观测退化处理与跨状态重分配机制

在实际飞行场景中，光照突变、运动模糊、局部遮挡以及目标姿态变化都可能使当前帧所选主策略的特征提取或位姿解算失败。为此，本文设计了层次化的观测退化处理机制以保证跟踪连续性，包括通用策略的单向退化后备链（3.4.1节）、混合观测模式的专属三级退化链与主 ROI 短路机制（3.4.2节），以及面向灾难性特征丢失的跨状态重分配机制（3.4.3节）。

### 3.4.1 单向退化后备链

在同一状态层级内，系统构建无环单向退化后备链。当主策略观测失败时，系统沿预设的退化方向逐级降级到信息利用率更低、但鲁棒性更强的后备策略，直至某一策略成功或退化链耗尽。策略链按照“AKAZE 描述子策略 → 二值角点策略 → 超分辨率微目标策略”顺序组织。退化方向始终从高判别力指向低判别力，且不跨区间折返，避免了策略间的往复震荡。

退化触发条件的定义同时覆盖特征提取与位姿解算两个环节：特征提取失败（成功标志为假或有效关键点数不足下限）触发降级；在单目配置下，特征提取成功而位姿解算失败同样触发降级——位姿判定被置于退化链循环内部逐策略执行，使某一策略的解算病态不会演化为整帧失败。此外，二维与三维对应关系按匹配序平行配对，当多边形近似产生的角点数多于模板角点时，尾部无对应角点被自然剔除，避免因数量不等而拒绝解算。退化链的触发条件形式化为公式3-2。

### 3.4.2 Dual-ROI 三级退化链与巨型主 ROI 短路

Dual-ROI 混合模式（3.3.4节）不参与通用退化链，而是采用与双模态观测结构相适应的专属三级退化链。

第一级为合并解算：两路观测点及其统一坐标系下的三维对应点合并为单次位姿求解的输入。当合并点数不足或解算失败时，进入第二级——仅边缘角点重解：切出合并观测中来自二值角点路的子集单独重新解算。该级还具有观测质量上的额外收益：纹理路中立体匹配失败的点，其右图坐标以左图坐标占位（视差为零），会持续污染交叉射线残差；而角点子集的右图观测来自真实右图角点提取，天然剔除了这一污染源。

第二级仍然失败时，进入第三级——中心区域退化链：在中心区域（class 1）ROI 上依次执行二值角点策略与超分辨率微目标策略。该级的三维模板坐标系建立在中心图案自身坐标系之上，依赖中心图案与靶标板共面同心的结构先验；解算采用冷启动而不继承板系位姿缓存，避免坐标语义混叠。

与三级链配合的还有巨型主 ROI 短路机制：当主 ROI 边长对画幅的覆盖比例超过阈值时，目标外角点已出视野，边缘角点提取在结构上必然失败，前两级的解算亦无成功可能。此时系统直接跳过前两级及其对应的整幅级特征提取开销，中心区域链成为唯一路径。该机制将注定失败的计算从流水线中裁剪，在极端近距离场景下同时改善鲁棒性与实时性。

### 3.4.3 跨状态重分配机制（CloseRange 回退）

针对极近距离或目标截断导致的灾难性特征丢失，引入跨状态重分配机制（原极近距离回退状态）。当目标运动导致 class 0 检测框消失、而中心区域 class 1 仍可检测时，系统强制回退：以 class 1 边界框为基础重新生成 ROI，并再次依据其面积落入的区间重新判定状态，转入相应的正常策略链。为使回退后的策略选择与仅含中心区域的观测相适应，系统为其提供了独立的面积阈值参数，避免了语义变化导致的策略误选。

## 3.5 位姿解算与后验校验

### 3.5.1 双目交叉射线 GPnP 优化

在双目配置下，系统采用基于交叉射线约束的全局位姿优化方法（GPnP）。GPnP 将位姿求解构造为最小化模型点对两条观测射线距离的非线性最小二乘问题，其残差向量由左右视图各自的向量叉积残差拼接构成（见公式3-3）。优化问题以四元数与平移向量构成的七维向量作为优化变量，采用 Levenberg–Marquardt 算法求解，并在双目模式下维护帧间位姿缓存（warm-start）以加速收敛。与重投影误差相比，交叉射线约束对深度方向的估计更为稳健。

### 3.5.2 首帧初值解算与单目位姿解算

为向 GPnP 提供可靠的初始猜测，系统在首帧或 warm-start 缓存失效时启用初始位姿解算器。该解算器以 RANSAC 方式进行鲁棒估计并辅以非线性精化。

在单目模式下，系统采用多候选竞争架构进行位姿解算。该设计源于一类典型失效模式：极小 ROI 下的平面目标（二维观测点高度聚集，跨度仅为数十像素量级）会使 EPnP 一类数值算法产生深度病态甚至发散的解，而同一输入下面向共面情形的闭式解 IPPE（Infinitesimal Plane-based Pose Estimation）却能以亚像素级重投影误差收敛——表明对应关系与相机内参均无问题，纯属求解器对微小平面目标的数值病态。据此，单目解算器不再依赖单一算法与发散回退机制，而是同时收集多路候选：（i）以上帧位姿为初值的时序种子迭代解，作为时序连贯性候选；（ii）EPnP 配合 RANSAC 的鲁棒解及其迭代精化解；（iii）IPPE 闭式解返回的至多两个解。每个候选入池前须通过统一校验——各分量有限、相机位于目标前方、平移范数处于工作距离区间、全点平均重投影误差低于上限；择优在有效候选中按平均重投影误差进行，并在误差近似的平票集内偏向时序种子候选，以兼顾求解精度与帧间连贯性（公式3-4、表3-2）。无效解在收集阶段即被拦截，系统中不存在以无效解作为初值或回退值的传播路径。

上述机制在观测点数恰为四点且存在时序种子时面临一个特殊问题：四点共面情形下迭代法恒收敛于种子盆地形，而传统的平坦验收容差与观测尺度无关，在小跨度目标上相当于过大的相对容差，陈旧种子解恒通过校验，形成“种子棘轮”式的深度冻结——目标持续逼近而深度估计被钉死于旧值，直至策略切换才以跳变形式释放。对此，系统将验收容差改为与二维观测跨度成比例并作上下限钳制的相对容差（公式3-5），并令种子解、冷启动迭代解与 IPPE 解同池竞争：劣质种子解因重投影误差显著更差而在收集阶段即被拦截，时序连贯性仅在误差真正相近时生效。该机制在保证不劣于原有行为的前提下，消除了逼近阶段的深度冻结。

## 3.6 基于 ESKF 的多模态信息融合

作为系统的跨模态状态估计后端，本模块接收 3.5 节输出的视觉观测位姿，并结合高频惯性测量单元（IMU）与雷达高度计等其它模态的测量数据，通过误差状态卡尔曼滤波（Error-State Kalman Filter, ESKF）进行多源融合。滤波器以惯性测量驱动高频运动预测，以视觉位姿与雷达高度作为离散观测进行修正，从而弥补视觉观测在极端退化场景下的短板，输出平滑、高频率且全局一致的最终六自由度位姿。本节重点阐述滤波器结构与观测模型、多源异步数据对齐、延迟测量反向传播、故障检测隔离与输出质量监控五个方面。

### 3.6.1 滤波器结构与视觉观测模型

滤波器采用误差状态参数化：名义状态由位置、速度、姿态四元数以及加速度计与陀螺仪的测量偏置构成，误差状态为其十五维扰动；世界坐标系取靶标模板坐标系。视觉前端输出的位姿描述目标在相机系下的变换，须先转换为相机在世界系中的位姿方可作为观测——旋转取解算结果的转置并施加模板系到世界系的修正旋转，平移按刚体关系换算并统一至国际单位制（公式3-7）。滤波器以首个通过校验的视觉位姿实施惰性初始化：直接设置名义状态而不施加更新，避免在协方差尚未收敛时引入更新冲突；视觉观测长时间中断超过阈值时，滤波器自动重置并等待重新初始化。

### 3.6.2 异步多源数据的排干式对齐

多源传感器的数据率与采样时刻互不相同：惯性测量达数百赫兹，雷达高度计为数十赫兹，而视觉观测受检测与特征提取耗时制约，频率最低且波动最大。为此，后端采用以相机帧为节拍的排干式对齐：各源样本携带时间戳进入缓冲区，每当视觉处理完成时，将缓冲中时刻不晚于当前相机时刻的惯性样本逐样本积分传播——保留高频信息而非按帧合并——雷达样本则逐样本经检验后更新。当视觉观测整体失效时，滤波器仅依靠惯性测量继续传播状态。这一“相机缺失、惯性推进”的桥接能力是融合后端维持位姿输出连续性的核心价值。

### 3.6.3 延迟测量的反向传播

视觉位姿是一种延迟测量：图像在曝光时刻 t₀ 成像，经目标检测、特征提取与位姿解算后于到达时刻 t₁ 才送入后端。若直接在 t₁ 时刻的状态上施加更新，相当于以 t₀ 的位姿纠正 t₁ 的状态，引入与相对运动速度和处理时延成正比的延迟误差。

为此，每条视觉观测显式携带曝光与到达双时间戳。当延迟超过判定阈值时，滤波器回退至不晚于 t₀ 的最近状态快照（快照按固定频率记录，仅保留在限定时间窗内），自该快照重放惯性测量至 t₀，在真实曝光时刻施加视觉更新，随后重放惯性测量至当前时刻并重建快照历史（见图3-3）。当延迟超出快照窗口而无法回退时，退化为按延迟时长对相机观测噪声作协方差膨胀的一阶有界近似后、按到达时刻更新，或直接丢弃该观测（公式3-8）。

### 3.6.4 故障检测与混合更新

视觉观测虽经 3.5.3 节的后验校验，仍可能存在单帧校验无法暴露的系统性偏差。为此，相机更新采用位置—姿态分离的混合策略：位置分量无条件参与更新；姿态分量仅在其新息经归一化新息平方（Normalized Innovation Squared, NIS）检验自洽、低于卡方门限时才追加（公式3-9），防止单帧坏姿态污染滤波状态。雷达高度观测同样须经跳变检验与 NIS 检验双重门控后方可更新。该机制赋予后端对单模态坏观测的故障检测与隔离能力，使个别坏帧在融合层被拒绝时系统行为仍然确定。

### 3.6.5 输出质量监控与退化分级

融合输出附带三档质量分级：视觉更新持续正常时为“正常”；视觉更新间隔超过软阈值时降为“退化”，位姿由惯性外推维持、可信度下降；间隔超过硬阈值时判为“过期”，滤波器自动重置，待下一个有效视觉观测重新初始化。位置协方差迹作为可信度的量化信号随位姿一同输出，供下游导航决策参考。该分级使系统在视觉短暂失效、长时间失效与恢复三种情形下均有明确且可预期的行为。
