| 可以填写为已验证 | 应继续保留为待验证 |

| 三轮策略与输出完全一致，右 YOLO 为零、PnP 跳过 | 位姿及融合稳定性、漂移和失效恢复效果 |
| 第29帧点9最大误差 0.6371 px及现有门槛的局限 | 更严格 FB 或稳健平面视差过滤的改善幅度 |
| 匹配阶段均值／P95及完整运行阶段计时 | 基于本数据相对旧前端的速度提升百分比，因为未做该对照 |
| 已保存报告中的历史单元测试和受控微基准，注明实验版本 | 将单元测试通过率解释为真实场景位姿精度 |

本次没有自然触发策略退化，故不能把成功路径覆盖当成失败退化鲁棒性验证。历史 60 对数据实验与新 150 对实验分别记录；不能沿用同一目录名就认定数据版本相同。

精度采用一轮独立样本统计，三轮只用于重复稳定性和耗时，避免重复扩大样本量。公开总体指标保留异常点，剔除异常后的结果仅作敏感性讨论。不同策略对应不同尺度和点数，不以组间耗时直接宣称算法优劣。
