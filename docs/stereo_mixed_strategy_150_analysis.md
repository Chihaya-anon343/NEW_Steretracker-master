# 150 对双目数据的 Dual-ROI／BC／TT 统计分析

2026-10-13。使用用户更新后的主配置，未修改算法、主配置或输入图片。启动前保存配置与 manifest 快照，运行后确认两者哈希未变化。结果保存于 `output/stereo_mixed_strategy_150/`。

## 实验条件与统计口径

| 项目 | 设置 |
|---|---|
| 数据 | `data/stereo_crop`，150 对，来源为 `上升image_00_间隔10` |
| 生成方式 | 同一原图左右裁剪，`uL-uR=d>0`；右图再施加亚像素垂直平移 |
| 视差真值 | 从 100 px 递减到 1 px，按每帧 manifest 数值计算 |
| 垂直偏移 | 每帧随机约 1–2 px；无额外光度扰动，随机种子 42 |
| 策略阈值 | TT：2,000 px²；Dual：class0 面积严格大于 18,000 px²且存在有效 class1 |
| 时序 | 开启，面积 EMA=0.5、连续确认 3 帧、迟滞系数 1.25／0.8 |
| 前端 | left_bc_lk、完整仅视差链、Dual 光流、ROI 金字塔与极线带搜索开启 |
| 匹配检查 | FB≤1 px、极线容差 3 px、NCC≥0.8；其余沿用原配置 |
| 输出模式 | 仅视差，无 PnP、位姿缓存更新或融合视觉观测；正式测量关闭可视化 |
| 环境 | Docker Release、C++17、OpenCV 4.5.4；主程序明确使用 CPU YOLO |
| 重复 | 1 次全序列预热＋3 次正式运行，均按相同顺序处理 |

精度与点数统计使用 run1 的 150 帧、1,559 个点，避免把重复运行当成新增独立样本。耗时汇总正式三轮的 450 个帧测量，预热不计入。统计按日志中的实际入口路线分组，CSV 最终策略另行核对，未依据视差大小或手工区间推断策略。

本数据验证稀疏对应和带符号视差，不提供真实深度、位姿或融合真值。`DualRoi_BCJ` 在仅视差模式表示两组匹配点汇总，不表示已经执行联合 GPnP。

## 分策略结果

| 策略 | 帧数／通过 | 匹配点／原始左点 | 点保留率 | 视差 MAE | RMSE | 最大绝对误差 | 匹配平均／P95 |
|---|---:|---:|---:|---:|---:|---:|---:|
| Dual-ROI | 23／23 | 446／460 | 96.96% | 0.007046 px | 0.008513 px | 0.0203 px | 4.110／7.320 ms |
| BC | 101／101 | 1,009／1,010 | 99.90% | 0.010172 px | 0.023021 px | **0.6371 px** | 2.398／5.761 ms |
| TT | 26／26 | 104／104 | 100% | 0.005139 px | 0.006784 px | 0.0176 px | 1.267／2.076 ms |
| 总体 | **150／150** | **1,559／1,574** | **99.05%** | **0.008942 px** | **0.019152 px** | **0.6371 px** | **2.464／5.897 ms** |

总体逐点绝对误差 P95 为 0.0175 px。1,558／1,559 个点的视差误差不超过 0.05 px；仅一个点超过 0.5 px，没有点超过 1 px。这是像素误差比例，不等同于模板物理编号正确率。

垂直偏移误差 MAE：Dual 0.012361 px、BC 0.012560 px、TT 0.015308 px，总体 0.012686 px。总体最大垂直误差 0.152 px。manifest 的 dy 保留三位小数，且图像平移含插值，相关误差含真值记录的舍入与图像插值影响。

三类处理的是不同目标尺度与不同点数，不能依据 TT 耗时和 MAE 较低就认定它在同输入下优于 BC。当前阈值有效覆盖了三种成功路径，但未在本数据自然触发 BC→TT 或 Dual→class1 的失败退化，不能据此宣称所有退化场景已经由此实验验证。

## 实际策略切换

| 数据帧 | 实际策略 |
|---|---|
| 1–9 | DualRoi_BCJ |
| 10 | BinaryCorner |
| 11–24 | DualRoi_BCJ |
| 25–124 | BinaryCorner |
| 125–150 | TinyTarget |

第 10 帧独立 debug 复核得到 class0 ROI 面积 311,922 px²，远大于 Dual 阈值，但未形成有效 class1 ROI，因此进入 BC。第 11 帧恢复 Dual；这一短暂变化是检测分支变化，不是 Dual 匹配失败后的退化。

第 125 帧独立检查得到 class0 ROI 面积 1,482 px²，进入 TT。全序列的切换还受面积 EMA、迟滞与连续确认影响，不能将阈值直接换算成固定距离。

23 个 Dual 帧均汇总两区域有效点，共 class0 229 个、class1 217 个。每个 TT 帧保留四点。全序列均无需全图重试、无需旧前端回退、无策略退化；每帧只构建一对金字塔，累计粗搜索尝试 141 次。

## 重复稳定性与耗时边界

三轮均 150／150 通过，每轮左 YOLO 150 次、右 0 次，PnP 为零。相对于 run1，run2 和 run3 的 300 个 CSV 均逐字节相同，入口策略、最终策略和帧状态也完全一致。

| 正式轮次 | YOLO 平均 | 单帧跟踪平均 | 提取＋匹配字段平均 | 实际端到端 FPS |
|---|---:|---:|---:|---:|
| run1 | 104.527 ms | 11.816 ms | 4.088 ms | 1.802 |
| run2 | 105.411 ms | 11.883 ms | 4.055 ms | 1.800 |
| run3 | 106.606 ms | 11.845 ms | 4.095 ms | 1.775 |
| 均值 | 105.515 ms | 11.848 ms | 4.079 ms | 1.793 |

匹配时间只包含光流／粗搜索／质量检查及匹配内重试，不包含 YOLO、图像读取、左提取及全部输出。当前日志名为“特征提取”的字段实际还包含匹配，属于跟踪时间的细分项，不能与跟踪时间重复相加。端到端 FPS 包含输入、调度与输出，不由 2.464 ms 匹配时间直接推算。

本实验未在相同新数据上运行旧双侧前端，因此不据此计算“相对原版提升百分比”。在已计时的 YOLO＋跟踪阶段，CPU YOLO 占约 90%，提示后续性能研究还需关注推理与输入链路。
